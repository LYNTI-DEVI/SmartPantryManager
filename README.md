Smart Pantry Manager
1. Application Name and Description
Application Name: Smart Pantry Manager
Smart Pantry Manager is an Android application developed to help users manage ingredients stored in their pantry. The application allows users to add, view, edit, and delete ingredients, as well as receive recipe recommendations based on the ingredients available
The application aims to simplify pantry management and help users identify recipes they can prepare using their existing ingredients
2. Database Choice and Justification
Chosen Database: SQLite
SQLite is used to store and manage the application's data locally on the Android device
SQLite was selected because it is lightweight, does not require a separate database server, and is suitable for storing structured information such as pantry ingredients and recipe data
I also used it because during my programming assignment we were asked to use SQL, but I ended up using SQLite, so I already had prior experience working with it
Using SQLite allows the application to manage its data locally without requiring a separate database server or an internet connection for database access
3. Setup and Run Instructions
Follow these steps to set up and run Smart Pantry Manager.
Prerequisites
•	Android Studio installed on your computer
•	A computer capable of running Android Studio
•	An Android emulator or a compatible Android device
•	An internet connection for downloading the project and any required dependencies
Setup Instructions
1.	Clone or download the Smart Pantry Manager project from GitHub.
Repository: https://github.com/LYNTI-DEVI/SmartPantryManager
2.	If you downloaded a ZIP file, extract it to a suitable folder on your computer.
3.	Open Android Studio.
4.	Select Open and navigate to the extracted SmartPantryManager project folder.
5.	Allow Android Studio to complete the Gradle sync and download any required dependencies
6.	If using an emulator, open Android Studio's Device Manager and start an available Android virtual device. Alternatively, connect a compatible Android device with USB debugging enabled
Running the Application
1.	Open the project using Android Studio
2.	Use the correct app run configuration
3.	Choose your Android emulator or connected device as the deployment target. I recommend Pixel 4
4.	Click the Run button
5.	Wait for Android Studio to build and install the application
6.	Once installation is complete, launch Smart Pantry Manager on the device
4. Main Application Features
•	Add ingredients to the pantry
•	View stored pantry ingredients
•	Edit ingredient information
•	Delete ingredients
•	Receive recipe recommendations based on available ingredients
•	View recipe details
•	Access the application's settings
